# Security policy

Only the latest 0.1.x release is supported. Do not publish sensitive inputs in issues. Use [GitHub private vulnerability reporting](https://github.com/KanadeK/localtime-audit/security/advisories/new) when available. If unavailable, open an issue containing only a request for a private reporting channel and no vulnerability details or private data.

This tool runs locally with your account's filesystem permissions. Reports and generated files can contain supplied paths or data; inspect them before sharing. It does not send telemetry. Consult the README for format and resource limits. No software can make a concurrently changing filesystem safe to treat as immutable.
